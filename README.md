西北太平洋再次迎來外洋來客。熱帶氣旋諾洛於東太平洋形成，香港時間今日清晨正式進入西北太平洋，成為2023年多拉以來首個東太來客。
諾洛於墨西哥西南海域發展為熱帶低氣壓，初期發展所阻，但最終在中太平洋增強為熱帶風暴並獲名。諾洛一度於夏威夷西南海域急劇增強，與最高級別的五級颶風僅一步之遙。隨後諾洛強度大上大落，但進入西北太平洋前重新增強，現時強度為三級颶風。
西北太平洋迎接外洋來客時有發生，但從東太平洋遠道而來的颶風則相當罕見，有紀錄以來發生少於十次。這是因為高壓脊須維持相當強度，才可令風暴一直在較低緯度西行；而夏威夷附近海域一般亦不利風暴發展，亦成為潛在東太來客的另一屏障。
值得留意的是，風暴越洋進入西北太平洋的情況，較多發生於厄爾尼諾年。這是因為赤道太平洋中部及東部的海溫較正常偏高，令對流活動以及風暴生成的位置隨之東移。

位於墨西哥灣的熱帶氣旋Isaias增強為北大西洋今年首個颶風，是自1905 年以來最遲「首颶」。
今年北大西洋熱帶氣旋活動顯著偏低，主因是現時在東太平洋發展的「超級厄爾尼諾」現象。在厄爾尼諾背景下，大西洋熱帶洋區的垂直風切變會較常年強，同時下沉氣流會較盛行，抑制熱帶低壓系統的對流活動及垂直結構發展，導致風季長時間處於低迷狀態。
目前 Isaias 正向東北偏北方向移動，受到墨西哥灣高海溫與大氣條件支持，預料強度仍有進一步提升的空間。Isaias 將以颶風強度移向路易斯安那州至佛羅里達州西部一帶，為當地帶來強風、暴雨及風暴潮威脅。

---

五年前的2021年10月8日至9日，熱帶氣旋獅子山襲港，雖然強度只達熱帶風暴級別，但其暖濕的偏南氣流與東北季候風匯聚，為本港帶來異常持續的大風雨天氣，打破當時有紀錄以來10月最高日雨量，以及帶來1961年以來距離香港最遠的八號風球。
10月8日，三號風球及黃雨生效期間，跑馬地一幅巨型棚架在狂風暴雨中倒塌，事件不幸造成一死兩傷。隨後雨勢進一步增強，天文台先後發出紅色及黑色暴雨警告。當日天文台總部共錄得329.7毫米雨量，刷新當時10月最高單日雨量紀錄（此紀錄已被2023年小犬襲港時打破）。
10月9日午夜，獅子山登陸海南島，但港澳兩地風力不跌反升，本港離岸持續吹烈風，西南部高地更達暴風；而澳門亦曾三橋同時錄得九級烈風，隨後更率先預告將會改發八號風球。本港天文台則在未有任何預告下於上午4時40分發出預警八號特別報告，並在兩小時後改發八號東南烈風或暴風信號。此做法屬近年罕有。
八號信號生效期間，由於與獅子山相關的雨帶不時來襲，本港部分地區風力維持在烈風水平，令天文台需要不斷押後「落波」時間。八號東南烈風或暴風信號最終維持22小時，打破最長八號東南信號的紀錄。

五年前的2021年10月13日，熱帶氣旋圓規為本港帶來2021年第二個八號信號，是繼獅子山襲港，相隔僅僅兩日半後天文台再次需要發出八號烈風或暴風信號，成為有紀錄以來不同風暴相隔最短時間的八號信號。
圓規的環流較廣闊、移速較快，加上在東北季候風的共同影響下，即使圓規最接近本港距離達360公里，本港仍有部分地區吹烈風，離岸間中達暴風，大老山更一度吹颶風。
而圓規亦為本港帶來較顯著的風暴潮。受圓規及東北季候風的共同影響下，維多利亞港及吐露港的海水高度3.38及3.53米，風暴增水超過1米。維港水位為有紀錄以來十月最高，亦是歷來第六高，僅次溫黛、山竹、天鴿、黑格比及樺加沙等歷史風暴。風暴潮及越堤浪夾擊之下不少沿岸及低窪地區出現水浸。
由於圓規襲港期間主要吹東至東北風，受東北季候風影響下未有轉吹東南風，八號東北烈風或暴風信號生效時間長達23小時20分鐘，是1973年以來單一方向信號生效時數的最長紀錄。
