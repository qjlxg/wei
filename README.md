受低壓系統影響，下週中後期本港驟雨增多，風勢較大。
季風槽將在南海至菲律賓以東海域建立，槽內可能有多於一個低壓區。南海的低壓區有機會發展為熱帶氣旋，但能否成旋，以及成旋時間和位置要視乎低層幅合強弱，目前有變數。
讀者亦要留意，熱帶氣旋生成前的路徑預測誤差更大，不應照單全收。由於季風槽東側可能有另一低壓區發展，副熱帶高壓脊的西伸幅度有機會受限，從而影響南海引導氣流強弱，以及南海低壓的移動方向和速度。
MET WARN 會繼續留意低壓系統的發展，適時更新。

夏威夷大島週末罕有受颶風侵襲。熱帶氣旋Lala雖然沒有登陸，但其眼壁仍為大島帶來颶風級風力。
大島島上有超過4000米高的冒納凱阿火山，比台灣和呂宋的山脈更高。Lala吹襲期間，山峰甚至一度下雪。
大島地形對熱帶氣旋的影響，亦引起氣象學家關注。結果顯示，今次人工智能路徑預報略勝一籌，解析度更高的颶風模式反而高估了短期路徑波動，錯誤預測Lala登陸大島。
厄爾尼諾期間，中太平洋熱帶氣旋會較活躍。今次夏威夷罕有「打風」，亦是厄爾尼諾正在發展的一大訊號。

五角大楼要求全美30家学术机构立即审查与中俄等国实体的现有合作
美国五角大楼8月17日宣布，已向30家美国国内学术机构发出正式通知，要求其对与包括中国等国“受关注外国实体”之间的学术、资金和研究合作立即启动全面审议，涵盖被纳入2019年《国防授权法案》(NDAA)“第1286条”名单的外国实体以及与“更名后的孔子学院有关联的组织”。
据悉，“第1286条”名单由美国国防部定期更新，旨在识别对美国科研项目和国家安全构成风险的外国高校和研究机构。今年7月23日，五角大楼公布更新名单，总数扩大至130家机构，涵盖中国、俄罗斯和伊朗三国。其中，中国机构达88家。与往年以军工院校为主的名单结构不同，此次更新首次将复旦大学、上海交通大学、四川大学、中山大学、山东大学、天津大学、西安交通大学等数十所中国顶尖综合性大学纳入限制范围。
五角大楼8月17日发表的声明称，这项行动由负责研究与工程事务的美国国防部副部长办公室执行，旨在保护美国纳税人资金支持的研究投入不会用于未经批准的技术转让和知识产权盗窃，并且不会被外国敌手利用。
五角大楼表示，为保留今后获取联邦研究经费的资格，接到通知的高校必须全面审查其对外合作关系，以及涉及敏感技术或受出口管制的研究项目，并采取相应整改措施，包括终止与存在问题的合作伙伴之间的关系。
五角大楼要求有关机构在8月31日之前，直接向其报告审查结果以及采取的行动。

我们一直在说产能过剩，仿佛产能过剩是天生的、注定的、无法逃避的，就好像孩子无法选择父母一样，但是吧，大家有考虑过么？
《我们为什么总是产能过剩？》
一、强大无比的地方政府
中央说要有光，全国每个市都造太阳。
开个玩笑，真实的案例是中央说新能源重要，各地立刻上产业园、抢企业、给土地、给贷款、给补贴。
一两个省市搞新能源没问题，七八个搞也没问题，几十个省几百个市一起搞呢？
每个地方单独看都合理，加起来自然就过剩了。
二、建多了比建少了强
如果一个产业爆发，你没提前布局，机会就永远被别的城市抢走了。你还要不要进步了？
如果建多了呢？无所谓啊！
还能降价、出口、续贷、补贴、兼并，慢慢消化。
所以地方政府天然会选择宁可多建，不能少建。
三、软预算约束
正常市场里，产能过剩以后，亏损企业会倒闭，产能自然退出。
但如果银行续贷、政府托底、债务展期、国企接盘呢？
于是出现一个很奇怪的结果：越亏越要生产，越生产越要降价，越降价越需要出口。
这也是“内卷”的一部分来源。
四、能不能无限“过剩”？
不能。肯定不能啊。
你可以过剩10%，本地消化不了就卖全国。
你可以过剩30%，全国消化不了就卖世界。
你可以过剩70%，世界消化不了就降价、压库存。
但是你过剩100%，那肯定不行。
现在，中国已经占全球制造业约30%，再继续高速扩张，就只能不断抢别国的市场份额。
所以美国开始加关税，欧洲开始保护本国产业。
不多说了，言至于此。

重要的课题是：如何让过剩，变成全社会的收入。
