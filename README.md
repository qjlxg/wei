近年人工智能發展迅速，社交媒體亦經常引用人工智能的天氣預報。但到底人工智能是否足以「洩露天機」呢？
現時活躍的熱帶氣旋白海豚是一個好例子。電腦模式預測白海豚將靠近沖繩，但隨後路徑可謂天女散花。部分電腦模式預測白海豚登陸浙江至江蘇一帶，但亦有其他電腦模式預測風暴在東海急轉彎北上，同時有部分電腦模式預測白海豚西南折並登陸福建。
翻查過去一週的電腦模式預報，亦可發現預測路徑由日本以東海域，不斷往西修正至東海。雖然人工智能模式有助減少路徑預報誤差，但超過一週的預報仍可有數百公里的差異。今次白海豚則涉及西風槽和副熱帶高壓脊的角力，誤差有機會更大，因此絕不應將電腦模式預報照單全收。
先前亦有傳媒引用人工智能模式，指白海豚有機會成為史上最強颱風。雖然現時人工智能模式對路徑預報頗爲拿手，但對強度預報仍然束手無策。熱帶氣旋強度除了取決於大氣條件，亦相當視乎核心結構變化，而電腦模式往往沒有足夠的解析度拿捏此因素。以今次白海豚為例，由於風暴不斷出現眼壁置換，導致其無法衝擊最極端的強度。

連綿不斷、陰雲不散的下雨天將暫告一段落。預料未來數日雨過天晴，天氣漸趨酷熱，但局部地區仍可能有幾陣「過雲雨」。
先前影響本港的低壓槽已移至北部灣附近。現時本港天氣屬「三不管」狀態，即副熱帶高壓脊未控制華南，同時西南氣流未影響沿岸，因此將是微風酷熱的天氣。
隨著熱帶氣旋白海豚靠近沖繩，預料其外圍下沉氣流於星期五至週末期間影響本港，屆時天氣持續酷熱，並轉吹西北風。讀者亦要留意，高溫天氣可能觸發局部地區強雷雨區發展。
至於過去一兩個月的下雨天有多持續？翻查資料，本港已累積超過2100毫米雨量，屬有記錄以來同期第六高；全港17個水塘中有11個達容量上限。同時，7月總日照時間是有記錄以來最低，僅有122小時。

熱帶氣旋鯨魚凌晨形成。鯨魚命運多舛，位於呂宋以東時一度被認定難產，隨後卻在呂宋以西的南海敗部復活。這個風暴的發展和呂宋地形到底有甚麼關係？
鯨魚巧妙之處在於背風低壓。所謂背風低壓，是指風暴靠近山脈時，另一個低壓在山脈另一面的背風側發展。鯨魚原中心在呂宋以東時，亦有背風低壓在呂宋以西發展，並伴隨對流。原中心後來缺乏對流支持而減弱消散，背風低壓則喧賓奪主，成為鯨魚形成的根基。
背風低壓亦是風暴靠近呂宋時，路徑出現短期波動的主因。但像鯨魚這種中心完全分裂的情況，則較常出現在較弱的熱帶氣旋。七年前的另一熱帶氣旋丹娜絲，靠近呂宋時亦有背風低壓發展，最後卻各行各路，舊中心在呂宋以東北上，新中心則一度獲日本氣象廳認定為熱帶低氣壓。
現時位於西北太平洋的熱帶氣旋白海豚增強初期，已不斷有傳媒報道鯨魚或被白海豚鯨吞；讀者亦可能好奇，到底最終會否成真。按照現時預測，鯨魚登陸呂宋島後會減弱；至於其殘餘低壓會否被吞併，仍須視乎兩個風暴的距離。電腦模式的預測顯示，雖然吞併可能性存在，但鯨魚亦有一定機會苟延殘存，隨後脫離白海豚的魔爪。

中国商务部长促英国审慎处理英钢国有化问题
英国政府宣布将中国民营企业控股的英国钢铁公司（British Steel）收归国有后，中国商务部长王文涛说，中国高度关注此事，并敦促英国审慎稳妥解决相关问题，为在英中资企业营造良好营商环境。
据中国商务部网站消息，王文涛星期二（7月28日）与英国商务部长雷诺兹举行视频通话，就中英经贸关系交换意见。
王文涛说，中国愿与英国做大合作蛋糕，加强在服务贸易、绿色转型、可再生能源等领域合作，推动双边贸易向上向前平衡，维护以世贸组织为核心的多边贸易体制。
他还说，中国高度关注英钢国有化问题，敦促英国遵守相关国际规则，切实履行中英投资保护协定有关义务，审慎稳妥解决此事，为在英中资企业营造良好营商环境。
英国政府7月16日宣布，将把中国民企敬业集团旗下的英钢公司全面国有化。敬业集团2020年以7000万英镑（1亿2000万新元）收购英钢。英钢位于英格兰北部斯肯索普（Scunthorpe）的工厂，有英国仅存的两座使用原生矿石炼钢的高炉。
英钢去年3月称，母公司敬业集团已投入超过12亿英镑维持公司运营，但每天亏损约70万英镑，并评估两座高炉在财务上难以持续运营。英钢隔月传出取消原材料订单，引发停炉关厂的担忧。
为保留其原生钢生产能力，英国国会去年4月通过紧急法案接管英钢，政府今年5月宣布将提出立法，促成英钢国有化。
对此，中国商务部新闻发言人7月17日指责英国“罔顾敬业对英经济社会做出的重要贡献，以国家安全之名，强行接管、进而对英钢实施国有化，严重损害了敬业的正当权益，严重挫伤了中国企业对英投资信心”。发言人也说，将支持中企运用法律手段维权，并将采取有力措施坚定维护中企利益。
