電腦模式下調未來兩三日的預測氣溫，是因為西風槽的南探幅度較先前預測較深。冷空氣強度較早前預期高，較可能翻越南嶺，從「中路」南下影響本港。
天文台預料，週一、二離岸吹強風，高地達烈風。在「風寒效應」影響下，離岸、高地及空曠地區的體感溫度或較實際低。
天氣明顯轉涼，讀者應按需要增添衣物保暖。隨著冷空氣緩和，星期四起氣溫顯著回升。

經歷稍涼的天氣後，本港未來數日天氣溫暖，週五、六需提防大驟雨及雷暴的風險。
電腦模式預料，東北季候風明日起會逐漸緩和。在缺乏冷空氣補充下，本港未來數日天氣顯著回暖，最高氣溫約26至28度。
此外，本港週五稍後至週六初時存在大驟雨及雷暴風險。電腦模式預料，一道活躍南支槽屆時將橫過華南，槽前盛行的上升氣流有利雨區發展。同時，近地面氣流亦較可能出現輻合，或誘發雨區形成。至於雨區位置、強度、影響範圍及時段，則視乎地面氣流輻合位置、強度，以及南支槽的移動速度，因此目前仍存變數。
讀者應留意天氣變化，週五、六出門前應帶備雨具。

---

預料本港週五、六有大驟雨、強陣風和雷暴風險。到底11月落大雨有幾罕見？
深秋時分，廣東沿岸一般受乾燥的東北季候風主導，甚少出現暴雨。但在2006年11月21日下午，強雷雨帶不斷由西向東橫過本港，黃色暴雨警告信號生效近5小時，至今仍保持年內最遲黃雨紀錄。究竟這場「深秋暴雨」是如何煉成的？
翻查當日大氣環境，可發現三個有利暴雨形成的條件。第一，近地面氣流出現顯著輻合，偏東氣流與較弱的偏北風在珠江口匯聚抬升。第二，大氣中低空吹較暖濕的西南風，一方面為暴雨提供「原材料」，另一方面「上冷下暖」格局令大氣更不穩定，促使氣流進一步向上升。第三，一道短波槽橫過華南，槽前盛行的上升氣流猶如「抽吸機」，將氣流往上吸。
週五、六的大氣配置，集齊廿年前黃雨當日的三大特點，但仍略有不同之處，最大分別是今次地面氣溫稍高，大氣「上冷下暖」的對比可能更明顯。另外值得留意的是，當年黃雨在晚間取消後，凌晨仍有強雨區持續影響珠江口，反映降雨不一定只集中在氣溫較高的日間。
這又是否代表今次會有黃雨？目前電腦模式對週五、六的降雨預報仍有分歧，主因是近地面氣流輻合位置和強度，以及南支槽的移動速度有變數，加上暴雨發展相當隨機，現今科技仍未能提前數小時預測雨區的發展位置、強度、持續時間和覆蓋範圍，因此判斷暴雨警告信號絕對言之尚早。無論如何，讀者出門前應留意天氣變化和最新消息。
