南华早报主编：中国正大力囤积黄金，其背后有着更大的目标——人民币国际化。上海负责合约定价，香港负责离岸金库保管，构建一条以黄金为支撑的货币国际化路径。
香港的角色发生了结构性转变，从一个简单的门户变成了国家推进金融安全和货币国际化的关键环节。
作为无可争议的全球贸易超级大国，中国力劝其他国家以人民币结算交易，却无意放松资本管制。但要让其他国家像持有美元或欧元一样持有人民币，外国央行必须确信人民币能够保值，并且可以兑换成有形抵押品。黄金和离岸人民币市场应运而生。
美国主导的对俄制裁给北京敲响了警钟，现在增加黄金储备已成为一种结构性需求。中国通过逐步以实物黄金替代美元资产，表明其国家资产负债表背后有庞大的、中性的“硬资产”支撑。这增强了外国，特别是西方以外的全球南方国家，对持有人民币计价债务或贸易顺差的信心。
历史上，黄金交易、定价和实物清算一直集中在伦敦和纽约。伦敦黄金市场仍占据全球每日交易量的70%以上，但上海黄金交易所的份额已上升至16%。更重要的是，上海黄金交易所主导着全球实物黄金交易，包括实物交割和金库保管。
中国还在上海黄金交易所推出了人民币计价黄金合约，并扩建了香港的离岸金库。这使得贸易伙伴，特别是金砖国家和中东石油出口国，能够接受人民币支付其商品，并立即在香港将其兑换成实物黄金，然后运回本国。这一被称为“黄金可兑换性”的过程，大大降低了中国贸易伙伴接受人民币的风险。
未来几十年，香港能否继续保持国际金融中心的地位，取决于能否为国家发展离岸人民币和黄金业务。如果能成为连接全球南方国家的黄金桥梁，香港的地位将得到无可撼动。

格隆汇10月6日｜荷兰国际分析师Francesco Pesole在一份报告中指出，如果近期法国国债因财政担忧而持续动荡，欧元可能面临进一步下跌。他表示，财政风险溢价上升以及市场对欧洲央行加息预期降温，正对欧元构成压力。尽管法国国债价格有所回落，帮助欧元从低点有所反弹，但持续反弹的可能性不大。他指出，目前法国债市的财政风险溢价仍相对有限，这意味着如果债券市场压力加剧，欧元仍有进一步下跌的空间，甚至可能跌至1.10美元。
