所以对于这类间歇性轮动板块，我们目前依然不做重点跟踪。
原因很简单，这些方向目前资金介入程度不高，主力仓位也不重，本身又缺乏指数带动作用。一旦市场重新出现调整，这类短线轮动方向往往也是最容易出现快速回落的。
主力资金虽然科技股出现了震荡，但都没有破坏趋势和结构，也因此维持对半导体，创新药和PCB的跟踪，不做调整。
整体观点保持不变：
1、指数维持震荡上行的判断，今天的极小线更多看作上涨过程中的中继整理。
2、机构资金的核心方向目前没有明显变化，继续围绕半导体（设备和材料）、创新药以及PCB等方向跟踪。

美国五角大楼8月17日宣布，已向30家美国国内学术机构发出正式通知，要求其对与包括中国等国“受关注外国实体”之间的学术、资金和研究合作立即启动全面审议，涵盖被纳入2019年《国防授权法案》(NDAA)“第1286条”名单的外国实体以及与“更名后的孔子学院有关联的组织”。
据悉，“第1286条”名单由美国国防部定期更新，旨在识别对美国科研项目和国家安全构成风险的外国高校和研究机构。今年7月23日，五角大楼公布更新名单，总数扩大至130家机构，涵盖中国、俄罗斯和伊朗三国。其中，中国机构达88家。与往年以军工院校为主的名单结构不同，此次更新首次将复旦大学、上海交通大学、四川大学、中山大学、山东大学、天津大学、西安交通大学等数十所中国顶尖综合性大学纳入限制范围。

五角大楼要求有关机构在8月31日之前，直接向其报告审查结果以及采取的行动。
