【沙德爾或成襲港前「最北風暴」】
天文台已經於下午6時10分，為重新增強成熱帶低氣壓的熱帶氣旋沙德爾發出一號戒備信號。
影響本港的熱帶氣旋，大多時會由相對較低緯度移入南海，除了於較遠距離「南掠西登」的風暴外，一般而言熱帶氣旋會於影響香港過後才到達高於香港緯度的位置。
根據天文台定位，沙德爾於登陸浙江前，中心曾一度北上至北緯28.6度，並最終於廣東西部至海南島一帶出海並重新增強，為香港帶來熱帶氣旋警告。
MET WARN綜合香港天文台歷年最佳路徑，並對比熱帶氣旋警告信號統計，相信沙德爾已打破2001年熱帶氣旋百合紀錄，成為自1961年有較完整定位紀錄以來，襲港前（即香港天文台發出熱帶氣旋警告前）曾到達最高緯度的熱帶氣旋。
天文台曾於2001年的熱帶氣旋年報提及，當年的百合為1960年8月的愛娜斯及伊蘭後，首次從太平洋以西南路徑越過台灣並影響香港的熱帶氣旋。雖然「高緯掃後欄」繼而令本港發出熱帶氣旋警告的風暴自踏入廿一世紀後有所增多。惟沙德爾除了「掃後欄」外，更是出海後重新增強，並由西向東移動影響本港。兩種路徑本身皆已不算常見，而兩者同時出現於同一股襲港氣旋更是極為罕見，可謂是絕無僅有的案例。

【非官方預測：MET WARN 最新評估】
MET WARN 目前評估，天文台就熱帶氣旋沙德爾發出三號強風信號的機會為「中等」。
【預測：受大陸氣流共同影響，離岸、高地或間中吹強風】
沙德爾強風區目前集中在中心南側。部分電腦模式預料，風暴移至本港東南方時，受大陸氣流的共同影響，北側環流的風力有機會稍微上升，本港離岸及高地屆時或間中吹強風，但實際風力須視乎沙德爾以及大陸氣流的強度。
【變數：中心整合位置、季風槽東側另一低壓系統】
沙德爾目前仍在整合中心，其路徑須視乎其中心最終整合的位置，因此變數較大。如果沙德爾採取較遠離本港的路徑，本港吹強風的機會便會有所降低。
此外，目前季風槽東側有另一系統，該系統亦有機會影響沙德爾的路徑，以及香港附近的氣壓梯度。
沙德爾預測路徑較複雜，目前不排除本週末風暴會再度靠近本港。MET WARN 會視乎沙德爾屆時的路徑和強度，評估須否再調整風球概率預報。
註：「中等」代表基於現有資料，MET WARN 評估天文台發出相關信號與否的機會相若，可以用「五五波」形容。
