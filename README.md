受熱帶氣旋白海豚的外圍下沉氣流影響，本港晚間氣溫下降幅度較細，日間升溫的起跑點因而較高。此外，本港現時吹西北風，廣東內陸昨日受下沉氣流影響期間，空氣已明顯加熱。內陸較熱的空氣被西北風帶至沿岸，導致本港日間顯著升溫。
翻查數據，天文台總部首三位高溫紀錄，均與熱帶氣旋下沉氣流有關。今日高溫與2015年熱帶氣旋蘇迪羅的個案較為類似，兩者均是西北風至偏西風將內陸較熱空氣帶至沿岸，加劇本港升溫幅度。
讀者亦要留意，現時紫外線指數達極高水平。在高溫及暴曬下，皮膚會吸收大量熱能，增加中暑風險。讀者應繼續做足防中暑和防曬措施，定期補充水分並盡量避免劇烈運動。如果出現頭暈、頭痛、噁心、氣促或神志不清等初步中暑症狀，應盡快休息和求助。

本港今日天氣極端酷熱，部分氣象站錄得破紀錄高溫，普遍地區氣溫上升至37度或以上，上水更一度接近40度。
天文台總部今日錄得最高氣溫36.9度，打破1884年有完整氣象觀測以來的最高紀錄。上水最高氣溫為39.8度，是天文台於1980年代開始設置自動氣象站以來的境內新高。
翻查紀錄，除天文台總部外，本港境內今日有另外8個氣象站刷新或追平創站以來最高氣溫紀錄。

本港今日多處錄得破紀錄高溫，但工作暑熱警告只維持在最低級別的黃色警告，引起公眾和媒體關注。
勞工處目前基於暑熱指數發出工作暑熱警告。暑熱指數除了參考氣溫，亦相當著重濕度、空氣流動和太陽熱輻射水平等影響人體散熱和吸熱的因素。
工作暑熱警告自2023年設立以來，從未發出紅色或黑色警告。翻查2014年至今京士柏的暑熱指數紀錄，只有4次達32或以上的紅色警告水平；最高為2019年8月12日的32.4，當日本港最高氣溫為34.0度，但由於是西南氣候風帶來的濕熱，所以暑熱指數較高。
相比之下，本港今日破紀錄高溫，主因是西北風將內陸較熱的空氣帶至沿岸。由於源自內陸的空氣較乾燥，加上今次伴隨一定風力，因此各區暑熱指數不算標青，十個參考站只有濕地公園一度達到紅色警告的標準。
乾燥的破紀錄高溫，伴隨低級別的暑熱警告，是否代表對公眾的風險較低？今日黃色暑熱警告生效期間，一名男子行山不幸中暑身亡。根據衛生署數據，本港過去五年每年有超過200宗因中暑入院的個案，當中死亡個案每年約為2至5宗，影響絕不亞於颱風和暴雨。
暑熱指數的計算，雖然各因素的比重有討論空間，但背後仍有一定科學基礎。至於工作暑熱警告的黃、紅、黑分級，則與近年世界各地提倡的基於影響預警有相似之處。
但制度的最大分別，在於外國由氣象機構基於數據、預報信心等因素作主觀判斷。而本港工作暑熱警告，則由勞工處基於單一數字發出。破紀錄高溫只對應最低級別的暑熱警告，一方面不符合常理和大眾觀感，另一方面亦未必能準確反映相關風險。暑熱警告制度是否存在改善空間，絕對值得有關部門研究。

经审理查明，2002年至2022年，陆文俊利用担任中国重机总经理、董事长，中国二重总经理、董事长，中国一重副总经理等职务上的便利，为有关公司和个人在业务承揽、佣金支付等事项上提供帮助，非法收受财物共计折合6798万余元。
法院认为，陆文俊的行为构成受贿罪，数额特别巨大，应依法惩处。鉴于他到案后如实供述自己罪行，主动交代办案机关尚未掌握的部分受贿犯罪事实；认罪悔罪，积极退赃，受贿赃款赃物及孳息已大部分追缴，可从轻处罚。法庭遂作出上述判决。
据悉，湘潭市中级法院今年5月9日公开开庭审理案件。陆文俊当庭表示认罪悔罪。
