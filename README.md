格隆汇10月9日｜据证券日报，近期，全国生猪市场呈现“低位回暖”态势。自9月30日生猪价格创下近三个月低点后，中国养猪网数据显示，截至10月8日，生猪（外三元）价格报10.3元/公斤，生猪（内三元）价格报10.63元/公斤，分别较国庆假期前上涨约0.24%、0.2%，且多地猪肉价格也较节前出现小幅反弹。“近期猪价反弹的直接推手来自供给端出栏节奏的变化，需求端的节假日消费拉动仅为次要支撑。”国家发展改革委国家信息中心经济预测部研究员尹伟华表示。对于本轮猪价反弹，业内已基本形成共识：其主要由短期情绪与供需节奏变化驱动，而非基本面反转。
