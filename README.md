雖然暴雨警告已經取消，但市民仍須警覺有關河道氾濫可能帶來的危險。

---

讀者會否覺得今年七月雖然炎熱，但高溫不如過去幾年的夏季難受；相反，今年七月更難受的，反而是連綿不斷的下雨天？
其實這並非錯覺。截至7月30日，本月的平均日最高氣溫、平均氣溫和平均日最低氣溫分別為31.2度、28.8度和26.7度，全部稍低於1991至2020年的氣候平均值。本月的累積雨量則高達719.4毫米，加上今日中午前後的暴雨，月雨量可能衝擊有記錄以來七月第二高。
雨量高，但極端高溫失蹤的盛夏，與厄爾尼諾開始發展有一定關係。厄爾尼諾期間的夏天，副熱帶高壓脊容易「山高皇帝遠」，難以穩定控制華南沿岸，一方面未能為本港持續帶來高溫天氣；另一方面，本港處於高壓脊邊緣時，亦有利雨區發展，導致下雨天氣頻密。
預料不穩定天氣未來兩三日仍會持續。正值英超亞軍曼城和意甲冠軍國際米蘭訪港，雖然啟德體育園可閉幕作賽，但兩隊球迷星期六出發觀賞球賽前，仍建議留意最新天氣資訊。

中国C919飞机高原型完成首次飞行试验
中国C919高原型首架机完成首次飞行试验。
据新华社，飞行试验星期三（7月29日）在上海浦东国际机场完成起降，完成全部预定试飞科目，标志着C919飞机系列化发展迈出重要一步。
据中国商飞网站介绍，C919高原型是在C919基本型的基础上，通过缩短机身和实施高原改装满足高原地区运输要求，座位数为140-160座，起降性能满足中国区域内全部高高原机场。
中国民航通常把机场分为高原机场和非高原机场，二者的界限为海拔高度1500米。
中国商飞2024年与西藏航空签署40架C919高原型和10架ARJ21高原型飞机订单。
