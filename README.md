这份名单经历数次更新，最新版本将130家外国高校和机构定性为从事“问题活动”，其中88家来自中国。复旦大学、上海交通大学和山东大学等多所中国综合性高校今年首次被列入。
中国商务部星期三（7月29日）在官网以发言人答记者问方式回应说，中国对此强烈不满、坚决反对。
发言人说，美国不断泛化国家安全概念，人为设置歧视性壁垒，将科研合作政治化、武器化、工具化，阻碍中美科研领域交流合作，“这与全球科技创新合作大势背道而驰”。
发言人敦促美国停止对中国科研机构无端抹黑，尽快纠正错误做法，为中国科研机构提供公平、公正、非歧视待遇。发言人还说，中国将采取必要措施，维护中方科研机构的正当合法权益，为正常科技交流合作保驾护航。

乌乌伊外长就袭船事件通话 双方均称无意升级局势
乌克兰外长瑟比加在伊朗谴责乌克兰袭击伊朗商船后，致电伊朗外长阿拉格齐，强调必须避免局势升级，并要求伊朗停止对俄罗斯的一切支持。
路透社报道，瑟比加星期一（7月28日）在社交平台X发文说，当天他与阿拉格齐通话，并说：“我强调，必须避免任何升级行动，并停止对俄罗斯入侵乌克兰战争提供支持。这场战争是非法的，必须结束。”
瑟比加说，两人进行了“坦诚”对话，目的是避免事态升级。乌方的一切行动旨在保卫乌克兰、抵御俄罗斯的侵略，无意针对民用船只和平民。
阿拉格齐也在X平台发文说，瑟比加向他保证，乌方无意袭击伊朗商船，基辅方面也不寻求局势升级。
阿拉格齐说：“伊朗也不寻求局势升级，但任何针对伊朗公民或利益的攻击都不可接受，由此造成的损失必须得到赔偿。”
另一方面，以色列外长萨尔在X平台发文说，他与瑟比加通电话，“讨论了我们两国面临的挑战，包括伊朗构成的威胁”。他表示期待与乌克兰深化合作。
乌克兰军方7月25日在里海袭击一艘伊朗商船，伊方对此强烈谴责，并召见乌克兰驻伊朗临时代办。阿拉格齐26日说，乌克兰袭击伊朗商船造成一名船员死亡，此举公然违反《联合国宪章》。他强调，乌克兰的所作所为“绝不会没有回应”。

中国商务部长促英国审慎处理英钢国有化问题
英国政府宣布将中国民营企业控股的英国钢铁公司（British Steel）收归国有后，中国商务部长王文涛说，中国高度关注此事，并敦促英国审慎稳妥解决相关问题，为在英中资企业营造良好营商环境。
据中国商务部网站消息，王文涛星期二（7月28日）与英国商务部长雷诺兹举行视频通话，就中英经贸关系交换意见。
王文涛说，中国愿与英国做大合作蛋糕，加强在服务贸易、绿色转型、可再生能源等领域合作，推动双边贸易向上向前平衡，维护以世贸组织为核心的多边贸易体制。
他还说，中国高度关注英钢国有化问题，敦促英国遵守相关国际规则，切实履行中英投资保护协定有关义务，审慎稳妥解决此事，为在英中资企业营造良好营商环境。
英国政府7月16日宣布，将把中国民企敬业集团旗下的英钢公司全面国有化。敬业集团2020年以7000万英镑（1亿2000万新元）收购英钢。英钢位于英格兰北部斯肯索普（Scunthorpe）的工厂，有英国仅存的两座使用原生矿石炼钢的高炉。
英钢去年3月称，母公司敬业集团已投入超过12亿英镑维持公司运营，但每天亏损约70万英镑，并评估两座高炉在财务上难以持续运营。英钢隔月传出取消原材料订单，引发停炉关厂的担忧。
为保留其原生钢生产能力，英国国会去年4月通过紧急法案接管英钢，政府今年5月宣布将提出立法，促成英钢国有化。
对此，中国商务部新闻发言人7月17日指责英国“罔顾敬业对英经济社会做出的重要贡献，以国家安全之名，强行接管、进而对英钢实施国有化，严重损害了敬业的正当权益，严重挫伤了中国企业对英投资信心”。发言人也说，将支持中企运用法律手段维权，并将采取有力措施坚定维护中企利益。

中国C919飞机高原型完成首次飞行试验
中国C919高原型首架机完成首次飞行试验。
据新华社，飞行试验星期三（7月29日）在上海浦东国际机场完成起降，完成全部预定试飞科目，标志着C919飞机系列化发展迈出重要一步。
据中国商飞网站介绍，C919高原型是在C919基本型的基础上，通过缩短机身和实施高原改装满足高原地区运输要求，座位数为140-160座，起降性能满足中国区域内全部高高原机场。
中国民航通常把机场分为高原机场和非高原机场，二者的界限为海拔高度1500米。
中国商飞2024年与西藏航空签署40架C919高原型和10架ARJ21高原型飞机订单。
