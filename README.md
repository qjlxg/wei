一道冷鋒正橫過本港，目前新界北部氣溫已較昨日同時段低4度左右。預料風勢逐漸增強，氣溫下降。

由於風勢較大，位於高地、離岸以及空曠地區的讀者，以及參加星期五至日樂施會毅行者活動的選手，應留意風寒效應所帶來的影響，體感溫度會較實際低。

本港將迎來濕涼天氣，日間氣溫不升反降。預料市區氣溫由今晚約20度，進一步降至明晚（星期五）最低約14度，新界部分地區及高地寒冷。
現時位於華北的冷高壓將繼續南壓，帶動冷空氣擴展至廣東沿岸。日間北風有所增強，屆時空曠地區、離岸及高地間中吹強風。在戶外或高地活動的讀者要特別留意，風寒效應會令體感溫度更低。
同時，一道雲雨帶會影響本港。如果雨勢持續將加劇蒸發冷卻，令本港降溫更明顯。
濕涼及風勢較大的情況下，讀者應按需要增添防風及保暖衣物，並帶備雨具。預料星期六早上天氣仍然清涼，但日間逐漸轉晴，隨後一兩日氣溫回升。

小摩展望2027年大宗商品：黄金有望重返4500美元
格隆汇11月24日｜摩根大通表示，预计随着美国在2027年转向去库存，铜价将向每吨1.1万美元迈进。摩根大通表示，锌供应受限的局面可能仍将支撑价格，预计2027年锌价均值在每吨3400美元左右。摩根大通预计，原油价格走低以及美联储自2027年一季度起维持利率不变，最终将推动黄金价格在2027年第四季度回升至每盎司4500美元，白银价格则将收复失地，回升至每盎司50多美元区间的中段水平。摩根大通表示，2027年下半年铂金投资需求将出现更强劲的增长势头，推动市场转向供应短缺，并进一步强化由黄金领涨的下半年涨势，推动铂金价格向每盎司1800美元迈进。摩根大通认为，供应过剩以及钯金需要相对于铂金维持更大折价，将使钯金价格前景在2027年保持相对稳定，预计价格将在每盎司1000至1200美元附近波动。摩根大通预计，到2027年底，铝价将跌向每吨2500美元。
