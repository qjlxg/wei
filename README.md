經歷稍涼的天氣後，本港未來數日天氣溫暖，週五、六需提防大驟雨及雷暴的風險。
電腦模式預料，東北季候風明日起會逐漸緩和。在缺乏冷空氣補充下，本港未來數日天氣顯著回暖，最高氣溫約26至28度。
此外，本港週五稍後至週六初時存在大驟雨及雷暴風險。電腦模式預料，一道活躍南支槽屆時將橫過華南，槽前盛行的上升氣流有利雨區發展。同時，近地面氣流亦較可能出現輻合，或誘發雨區形成。至於雨區位置、強度、影響範圍及時段，則視乎地面氣流輻合位置、強度，以及南支槽的移動速度，因此目前仍存變數。
讀者應留意天氣變化，週五、六出門前應帶備雨具。

預料本港週五、六有大驟雨、強陣風和雷暴風險。到底11月落大雨有幾罕見？
深秋時分，廣東沿岸一般受乾燥的東北季候風主導，甚少出現暴雨。但在2006年11月21日下午，強雷雨帶不斷由西向東橫過本港，黃色暴雨警告信號生效近5小時，至今仍保持年內最遲黃雨紀錄。究竟這場「深秋暴雨」是如何煉成的？
翻查當日大氣環境，可發現三個有利暴雨形成的條件。第一，近地面氣流出現顯著輻合，偏東氣流與較弱的偏北風在珠江口匯聚抬升。第二，大氣中低空吹較暖濕的西南風，一方面為暴雨提供「原材料」，另一方面「上冷下暖」格局令大氣更不穩定，促使氣流進一步向上升。第三，一道短波槽橫過華南，槽前盛行的上升氣流猶如「抽吸機」，將氣流往上吸。
週五、六的大氣配置，集齊廿年前黃雨當日的三大特點，但仍略有不同之處，最大分別是今次地面氣溫稍高，大氣「上冷下暖」的對比可能更明顯。另外值得留意的是，當年黃雨在晚間取消後，凌晨仍有強雨區持續影響珠江口，反映降雨不一定只集中在氣溫較高的日間。
這又是否代表今次會有黃雨？目前電腦模式對週五、六的降雨預報仍有分歧，主因是近地面氣流輻合位置和強度，以及南支槽的移動速度有變數，加上暴雨發展相當隨機，現今科技仍未能提前數小時預測雨區的發展位置、強度、持續時間和覆蓋範圍，因此判斷暴雨警告信號絕對言之尚早。無論如何，讀者出門前應留意天氣變化和最新消息。

格隆汇11月19日｜受国际金价传导，国内品牌金饰价格连续8个交易日下跌。今日，老庙黄金足金饰品报1125元/克，8日跌去108元，较年内高点1722元/克跌597元；老凤祥报1132元/克，8日跌去104元，较高点跌去581元；周大福报1132元/克，8日跌去107元，较高点跌去574元。目前多家品牌金饰克价较年内高点回撤幅度均在三成以上，其中老庙跌幅已接近35%。

投资者质疑黄金的“避险”地位
格隆汇11月19日｜投资者正日益质疑黄金在投资组合中作为“避险资产”的传统地位。近几个月来，尽管股票等风险资产遭遇剧烈抛售，但黄金价格却大幅下挫。基金公司Ninety One的投资组合经理乔治·切夫利表示，黄金的表现“更像是一种风险资产”，而非风险对冲工具。Peel Hunt的分析师指出，本周金价跌至新低“并无明确的触发因素”；事实上，油价下跌和债券收益率走低，本应为金价提供支撑。他们补充称，金价跌破每盎司3800美元，看起来像是投资者出现了“潜在的投降式抛售”。这引发了人们的担忧，即“市场情绪正在恶化，越来越多的投资者认为有必要平仓离场，在进入新的一年之际选择观望”。世界黄金协会亚洲及欧洲市场策略师约翰·里德表示，今年金价的疲软“在很大程度上是由于西方加杠杆的投机者和投资者——即那些短期参与者——造成的”；他们在金价快速上涨时入场，而在经济环境发生变化时又迅速离场。蒙特利尔银行董事总经理兼大宗商品分析师海伦·阿莫斯指出，已有投资者发出警示，称他们不再将黄金视为股票投资组合中的多元化配置工具。

印度10月石油进口量飙升至创纪录水平
格隆汇11月19日｜贸易消息来源的数据显示，10月份印度原油进口量达到创纪录的558万桶/日，较上月增长4.7%；这主要是因为多数炼油厂提高了原油加工量，以满足国内日益增长的燃料需求。

伊拉克大幅折价出售12月巴士拉原油
格隆汇11月19日｜一份报价文件显示，伊拉克国家石油营销组织（SOMO）已提出以较目的地市场基准价每桶最高低33美元的折扣，出售12月装船的巴士拉原油。文件显示，此次报价适用于12月装船的原油，具体供应量由买方确定。SOMO对巴士拉中质原油的报价为较目的地市场基准价每桶折价29.20美元，对巴士拉重质原油的报价为每桶折价33美元。此次折扣幅度较10月装船的原油略有收窄。当时，SOMO以离岸价（FOB）出售巴士拉中质原油和巴士拉重质原油，折扣分别为每桶34.50美元和37美元。

IEA：全球制冷需求已超过供暖需求
格隆汇11月19日｜国际能源署(IEA)表示，随着收入水平提高和气温上升，空调使用量激增，全球用于建筑制冷的电力需求首次超过了供暖需求。国际能源署在周四发布的《世界能源展望》报告中指出，在欧洲等传统上气候较为凉爽的地区，异常炎热的夏季正在加速这一转变。在报告所设想的三种情景中，到2035年，制冷需求将占能源需求增长的40%以上。

沙特取代阿联酋成为印度第二大石油供应国
格隆汇11月19日｜贸易数据显示，受伊朗战争扰乱地区供应以来，印度10月份从沙特进口的石油量首次超过从阿联酋进口的石油量。沙特通过提供折扣原油，试图夺回市场份额。数据显示，俄罗斯仍是印度10月份最大的石油供应国，其次是沙特和阿联酋。印度从沙特进口的石油增至8个月高点，约为79万桶/日；从阿联酋进口的石油则降至7个月低点，为61.2万桶/日。印度10月份石油进口量创下558万桶/日的历史新高，较9月份增长4.7%，同比增长6.9%。
