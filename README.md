目前尚不清楚这是否是同一次空袭。以军也称，袭击结果仍在评估中，并未透露是否成功击毙阿里。哈马斯则未立即对此发表评论。
造成五人死亡的空袭摧毁了整栋公寓楼并引发火灾。目击者艾哈迈德（Ahmed al-Dahdouh）说，事发时一家人正在睡觉，突然听到连续的袭击和剧烈的爆炸声，孩子们惊醒并开始惊慌地奔跑和尖叫。
他回忆道，自己跑出来后发现，邻居的房子已被炸毁。“现场有被炸得肢体残缺的死者，包括妇女、男人和儿童。我们开始把他们拉出来，他们被废墟掩埋，散落得到处都是。”

耶路撒冷希腊东正教牧首区也在星期六发表声明，哀悼迈萨和玛丽，向遇难者家属表示慰问，并祈祷战争和轰炸尽早结束。
近期，以色列指责哈马斯违反停火协议重新武装并发动袭击，加大对哈马斯的打击力度；哈马斯则予以否认，并反指以色列破坏加沙和平协议。
加沙卫生官员透露，自去年10月达成停火协议以来，已有至少1400名巴勒斯坦人死于以色列的炮火。同期也有四名以军士兵在加沙被武装分子打死。
