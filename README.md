就法德要求欧盟强化贸易防御等保护主义工具，中国商务部新闻发言人10月6日表示，保护主义提升不了竞争力，“脱钩断链”只会损人不利己。
据媒体报道，10月5日，法国和德国向欧委会提交非正式文件，要求欧盟强化使用贸易防御措施，并推出多项保护主义新工具。
对此，发言人强调，中方始终认为，相互依赖不是风险，利益交融不是威胁，开放合作才是发展的正道。希望法国和德国作为全球重要经济体，能够坚持开放合作和自由贸易，遵守世贸规则，不要鼓动欧盟动辄使用保护主义工具，更不要将经贸问题政治化和泛安全化，避免以错误方式走错误道路并最终反噬自己。
中欧经贸关系体量巨大、利益深度交融。2025年中国与欧盟货物贸易总额达5.93万亿元人民币，欧盟占中国外贸总额的13%；德国是中国在欧洲最大贸易伙伴，2025年中德贸易额1.51万亿元，中国时隔一年重返德国最大贸易伙伴国；法国是中国在欧盟内第三大贸易伙伴，2025年中法贸易额839.6亿美元。

泰国拟下调生物燃料税以减少原油进口
格隆汇10月7日｜泰国政府正考虑下调生物燃料消费税，压低价格并拉动消费。能源部发言人蓬波尔・约德孟查伦（Pongpol Yodmuangcharoen）在周三新闻发布会上表示，能源部与财政部正在拟定减税方案。蓬波尔称，生物燃料由汽油或柴油混合生物质燃料制成，可在本土低成本生产。生物汽油与生物柴油的消费税约为每升6泰铢。扩大生物燃料使用将有助于减少原油进口，减轻政府燃油补贴压力。
