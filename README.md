2025年6月，试验车在7.1秒内加速至650公里/小时；同年7月，提速至约697公里/小时（433英里/小时）；11月，再次提升至约798公里/小时（496英里/小时）。

用于本次实验的1公里测试线最初即定位为科研平台，用于验证可应用于磁悬浮超高速交通研发的相关方案。此外，该基础设施还服务于电磁橇及航天电磁发射技术的研究。
因此，该试验车本质上是一个用于验证新技术方案的平台，而非即将投入运营的通勤列车原型。此次在湖北完成的试验，使专家得以检验磁悬浮与电磁推进系统在800公里/小时速度下的实际表现。
