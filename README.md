截至下午3時20分，上水錄得的最高氣溫高達39.7度，除打破該站紀錄外，亦打破自1980年代天文台於各區安裝自動氣象站以來的境內最高氣溫。

---

本港今日天氣極端酷熱，部分氣象站錄得破紀錄高溫，普遍地區氣溫上升至37度或以上，上水更一度接近40度。
天文台總部今日錄得最高氣溫36.9度，打破1884年有完整氣象觀測以來的最高紀錄。上水最高氣溫為39.8度，是天文台於1980年代開始設置自動氣象站以來的境內新高。
翻查紀錄，除天文台總部外，本港境內今日有另外8個氣象站刷新或追平創站以來最高氣溫紀錄。

---

本港今日多處錄得破紀錄高溫，但工作暑熱警告只維持在最低級別的黃色警告，引起公眾和媒體關注。
勞工處目前基於暑熱指數發出工作暑熱警告。暑熱指數除了參考氣溫，亦相當著重濕度、空氣流動和太陽熱輻射水平等影響人體散熱和吸熱的因素。
工作暑熱警告自2023年設立以來，從未發出紅色或黑色警告。翻查2014年至今京士柏的暑熱指數紀錄，只有4次達32或以上的紅色警告水平；最高為2019年8月12日的32.4，當日本港最高氣溫為34.0度，但由於是西南氣候風帶來的濕熱，所以暑熱指數較高。
相比之下，本港今日破紀錄高溫，主因是西北風將內陸較熱的空氣帶至沿岸。由於源自內陸的空氣較乾燥，加上今次伴隨一定風力，因此各區暑熱指數不算標青，十個參考站只有濕地公園一度達到紅色警告的標準。
乾燥的破紀錄高溫，伴隨低級別的暑熱警告，是否代表對公眾的風險較低？今日黃色暑熱警告生效期間，一名男子行山不幸中暑身亡。根據衛生署數據，本港過去五年每年有超過200宗因中暑入院的個案，當中死亡個案每年約為2至5宗，影響絕不亞於颱風和暴雨。
暑熱指數的計算，雖然各因素的比重有討論空間，但背後仍有一定科學基礎。至於工作暑熱警告的黃、紅、黑分級，則與近年世界各地提倡的基於影響預警有相似之處。
但制度的最大分別，在於外國由氣象機構基於數據、預報信心等因素作主觀判斷。而本港工作暑熱警告，則由勞工處基於單一數字發出。破紀錄高溫只對應最低級別的暑熱警告，一方面不符合常理和大眾觀感，另一方面亦未必能準確反映相關風險。暑熱警告制度是否存在改善空間，絕對值得有關部門研究。

在午夜時分，部分地區氣溫仍然維持在33度或以上的酷熱水平，當中流浮山的氣溫達34.1度。
讀者應留意，晚間降溫並不代表中暑風險完全消除。混凝土、鋼筋等建築材料已於日間吸收大量熱能，並於晚間以輻射熱形式釋放，室內體感仍可能較悶熱。於室內空氣不流通的環境，即使凌晨時分，身體於靜止狀態仍然有中暑風險。
讀者就寢時，可考慮開冷氣降低室內溫度，或保持空氣流通以排走室內熱力。如果出現頭暈、頭痛、噁心、氣促或神志不清等初步中暑症狀，應盡快休息和求助。

        在前面的股评里，我明确说多点开花是可以的，但不能是遍地开花，说的是热点板块可以有几个，但不能太多，否则后续资金无以为继，市场极有可能快速回落，一语成谶，今天下午就是市场在遍地开花后资金跟不上展开的调整，完全在意料之中！
         昨天市场还是一片“多点开花”，房地产、消费、医药、通信、CPO等多个方向轮番表现，超过4100只个股上涨。这样的行情当然很好，但问题也恰恰隐藏在这里——当热点从多点开花变成遍地开花，资金反而容易跟不上。今天的冲高回落，就是这种现象的一次体现。
         一个健康的市场，热点适当扩散是好现象。主线启动之后，资金从龙头向第二梯队扩散，再从一个行业向其他行业轮动，能够形成赚钱效应的扩散。这种“多点开花”，说明市场活跃度提高。但是，如果每一个方向都想成为热点，资金就会出现明显的分流。
        尤其是目前A股每天两万亿元左右的成交规模，虽然已经非常庞大，但面对如此众多的热点，仍然很难支持所有板块持续上涨。于是就会出现一种熟悉的现象：昨天上涨的板块今天调整，今天新热点起来，明天又换另外一个方向。这就是典型的存量资金博弈。
         盘面上，创新药、CRO、医疗服务继续强势，CPO、算力租赁、通信设备等科技方向同样活跃；另一方面，贵金属、油气等此前表现较好的资源方向出现调整。这说明资金并没有离场，而是在极其快速地进行内部切换。我认为，这才是今天行情真正的关键词：不是全面看空，而是资金不够支持全面上涨。
        当一天之内有超过4100只股票上涨，房地产、消费、通信、教育、医药等多个方向同时表现的时候，短线情绪已经明显升温。这种情况下，第二天出现分化是非常正常的。市场不可能每天让所有人赚钱。
          明天最重要的不是预测指数涨多少，而是看三个信号：第一，看成交量是否继续保持高位；第二，看今天强势的医药、CPO能否继续获得资金承接；第三，看贵金属、小金属等前期主线调整之后是否出现回流。只要这三个信号没有同时恶化，我仍然认为这属于牛市中的正常分歧，而不是行情结束。
