近年人工智能發展迅速，社交媒體亦經常引用人工智能的天氣預報。但到底人工智能是否足以「洩露天機」呢？
現時活躍的熱帶氣旋白海豚是一個好例子。電腦模式預測白海豚將靠近沖繩，但隨後路徑可謂天女散花。部分電腦模式預測白海豚登陸浙江至江蘇一帶，但亦有其他電腦模式預測風暴在東海急轉彎北上，同時有部分電腦模式預測白海豚西南折並登陸福建。
翻查過去一週的電腦模式預報，亦可發現預測路徑由日本以東海域，不斷往西修正至東海。雖然人工智能模式有助減少路徑預報誤差，但超過一週的預報仍可有數百公里的差異。今次白海豚則涉及西風槽和副熱帶高壓脊的角力，誤差有機會更大，因此絕不應將電腦模式預報照單全收。
先前亦有傳媒引用人工智能模式，指白海豚有機會成為史上最強颱風。雖然現時人工智能模式對路徑預報頗爲拿手，但對強度預報仍然束手無策。熱帶氣旋強度除了取決於大氣條件，亦相當視乎核心結構變化，而電腦模式往往沒有足夠的解析度拿捏此因素。以今次白海豚為例，由於風暴不斷出現眼壁置換，導致其無法衝擊最極端的強度。

連綿不斷、陰雲不散的下雨天將暫告一段落。預料未來數日雨過天晴，天氣漸趨酷熱，但局部地區仍可能有幾陣「過雲雨」。
先前影響本港的低壓槽已移至北部灣附近。現時本港天氣屬「三不管」狀態，即副熱帶高壓脊未控制華南，同時西南氣流未影響沿岸，因此將是微風酷熱的天氣。
隨著熱帶氣旋白海豚靠近沖繩，預料其外圍下沉氣流於星期五至週末期間影響本港，屆時天氣持續酷熱，並轉吹西北風。讀者亦要留意，高溫天氣可能觸發局部地區強雷雨區發展。
至於過去一兩個月的下雨天有多持續？翻查資料，本港已累積超過2100毫米雨量，屬有記錄以來同期第六高；全港17個水塘中有11個達容量上限。同時，7月總日照時間是有記錄以來最低，僅有122小時。

---

熱帶氣旋鯨魚凌晨形成。鯨魚命運多舛，位於呂宋以東時一度被認定難產，隨後卻在呂宋以西的南海敗部復活。這個風暴的發展和呂宋地形到底有甚麼關係？
鯨魚巧妙之處在於背風低壓。所謂背風低壓，是指風暴靠近山脈時，另一個低壓在山脈另一面的背風側發展。鯨魚原中心在呂宋以東時，亦有背風低壓在呂宋以西發展，並伴隨對流。原中心後來缺乏對流支持而減弱消散，背風低壓則喧賓奪主，成為鯨魚形成的根基。
背風低壓亦是風暴靠近呂宋時，路徑出現短期波動的主因。但像鯨魚這種中心完全分裂的情況，則較常出現在較弱的熱帶氣旋。七年前的另一熱帶氣旋丹娜絲，靠近呂宋時亦有背風低壓發展，最後卻各行各路，舊中心在呂宋以東北上，新中心則一度獲日本氣象廳認定為熱帶低氣壓。
現時位於西北太平洋的熱帶氣旋白海豚增強初期，已不斷有傳媒報道鯨魚或被白海豚鯨吞；讀者亦可能好奇，到底最終會否成真。按照現時預測，鯨魚登陸呂宋島後會減弱；至於其殘餘低壓會否被吞併，仍須視乎兩個風暴的距離。電腦模式的預測顯示，雖然吞併可能性存在，但鯨魚亦有一定機會苟延殘存，隨後脫離白海豚的魔爪。

---

受熱帶氣旋白海豚的下沉氣流影響，預料週末本港天氣極端酷熱，新界氣溫再高兩三度。
高溫亦有機會觸發強對流活動。預料星期五及週末期間局部地區存在大驟雨、強陣風和雷暴風險。讀者須留意今次熱對流風險不一定集中在下午時分，發展位置亦較隨機。如未來兩三日有戶外活動計劃，應多加留意天氣變化。
由於高溫天氣持續，讀者應做好防曬、防中暑措施，並留意身邊有需要人士的健康狀況。

据白宫发布的行政令文本，第一项行政令列举了不适用“出生公民权”的部分特定外国人在美新生子女，如“敌对外国势力”人员的子女；第二项行政令针对赴美生育从而使新生儿获得美国公民身份的“生育旅游”。
特朗普政府主张，新命令不受最高法院裁决的限制，并将包括以生育旅游为目的入境的人。新命令也限制外国政府雇员和敌国人士在美生下的子女的权利。
白宫副幕僚长米勒星期四在白宫告诉记者：“自本行政令签署之日起，这种生育旅游的做法即被禁止。”
主张降低移民人数的移民研究中心估计，2016年至2017年间，约有2万至2万5000名母亲赴美进行“生育旅游”。
如果国会批准一项取消美国领地出生者自动取得公民权的法律，新行政令也可能影响在这些领地出生的人。
法律专家认为，鉴于最高法院此前的裁决，目前还不清楚这些行政命令可能产生什么影响。移民权益倡导者则批评，这是试图规避最高法院裁决的举措，最终将在法院败诉。
前拜登政府官员、拉美裔民权与倡导组织UnidosUS的弗莱沙克说：“就在五周前，最高法院明确指出，出生公民权不容总统随心所欲更改，这是一项已确立并延续了150多年的宪法保障。如今颁布的这些行政命令，不过是企图绕过那项裁决。”
美国媒体报道说，特朗普的最新行政令也很可能在法庭上受到挑战，因为美国宪法第14修正案规定，所有在美国出生或归化并受美国司法管辖的人均为美国公民。

印度东北部洪灾致近百人死亡
据印度政府最新统计，东北部洪灾已造成近百人死亡，阿萨姆邦遭遇多年来最严重的洪灾之一，多个村庄被泥石流掩埋。
阿萨姆邦（Assam）洪灾已造成至少97人死亡，近17万人受灾，暴涨的河水淹没了房屋和农田，数千人被迫躲入临时避难所。
洪水淹没了约1.4万公顷的农田，面积几乎是巴黎的1.5倍。
法新社记者在受灾最严重的锡瓦萨加尔地区（Sivasagar）目睹了半淹没的房屋、连根拔起的树木和泥石流掩埋的车辆。
阿萨姆邦首席部长希曼塔·比斯瓦·萨尔马（Himanta Biswa Sarma）星期五（8月7日）发布了一段视频，视频中他正在安慰一个13岁男孩的父母。男孩在试图从洪水中救出他的宠物狗时不幸溺亡。
印度卫生部长纳达（J.P. Nadda）星期四视察灾区后说，洪水淹没了一个又一个村庄，灾情“规模巨大，恢复正常秩序需要时间。”
与南亚次大陆大部分地区一样，每年6月至9月季风期间，阿萨姆邦都会发生洪水，因为印度最大的河流布拉马普特拉河（Brahmaputra）及其众多支流经常泛滥。
专家指出，气候变化加上规划不善的发展，正在加剧洪水灾害的发生频率、严重程度和影响。
居民和官员将洪灾加剧归咎于邻近的那加兰邦（Nagaland）的非法煤矿开采，称洪灾影响了历史上不易发生洪灾的地区。

美上诉法院裁决：禁特朗普耗4亿美元建造白宫宴会厅
美国联邦上诉法院下令，要求总统特朗普总统的政府停止在白宫东翼拆除地块上建造一座耗资4亿美元（5.13亿新元）的宴会厅。此举对这名共和党领导人造成了重大打击，也考验着他的总统权力。
位于华盛顿的哥伦比亚特区巡回上诉法院星期五（8月7日）以二比一的投票结果，维持了国家历史保护信托基金（National Trust for Historic Preservation）此前赢得的初步禁令。信托基金去年提起诉讼，指控特朗普政府在未获得国会授权的情况下拆除了东翼，并开始建造一座面积达9万平方英尺（8360平方公尺）的宴会厅。
路透社报道，法官在裁决书中写道：“是否应该建造一座大型宴会厅应由国会决定，而非行政部门自行决定。国会并未赋予行政部门不受限制的权力，使其可以随意重新设计、改造和重建白宫——这座人民的殿堂——以满足某位总统的个人意愿。”
上诉法院将裁决暂缓14天执行，以便特朗普政府向美国最高法院提起上诉。白宫和司法部尚未对此置评。此前，美国地区法官理查德·莱昂（Richard Leon）两次叫停了该地块的地上施工，但允许地下工程继续进行，特朗普随后提起上诉。
莱昂是共和党前总统乔治·W·布什任命的法官，他裁定没有任何联邦法规“赋予总统”在未经国会批准的情况下建造宴会厅所需的权力。
特朗普政府称，建造宴会厅对于举办大型正式活动和保障白宫安全至关重要。这是特朗普政府为重塑华盛顿中心地带的政府建筑和国家纪念碑格局而采取的多项举措中最宏大的一项。
在另一起诉讼中，一名法官最近裁决，特朗普的名字非法添加到肯尼迪表演艺术中心的外部，并下令将其移除。

陈婧：当大学老师也难保“铁饭碗”
中国职场的内卷风刮进象牙塔。过去一周，上海同济大学的一份内部文件在网上流传，令学术圈人心惶惶。
这份7月31日公布的《关于开展2026年度全校专业技术职务评聘及考核续聘工作的通知》明确，学校对专业技术职务实行聘期考核管理，不再签订长期聘任协议。今后，预聘教师每三年考核一次，原有长聘教师每六年考核一次、每三年中期考核。考核不合格者，将面临降薪、降级、转岗甚至解聘。
