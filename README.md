截至下午1時15分，天文台總部錄得最高氣溫36.7度，已打破1884年有完整氣象觀測以來的最高氣溫紀錄。
受熱帶氣旋白海豚的外圍下沉氣流影響，本港晚間氣溫下降幅度較細，日間升溫的起跑點因而較高。此外，本港現時吹西北風，廣東內陸昨日受下沉氣流影響期間，空氣已明顯加熱。內陸較熱的空氣被西北風帶至沿岸，導致本港日間顯著升溫。
翻查數據，天文台總部首三位高溫紀錄，均與熱帶氣旋下沉氣流有關。今日高溫與2015年熱帶氣旋蘇迪羅的個案較為類似，兩者均是西北風至偏西風將內陸較熱空氣帶至沿岸，加劇本港升溫幅度。
讀者亦要留意，現時紫外線指數達極高水平。在高溫及暴曬下，皮膚會吸收大量熱能，增加中暑風險。讀者應繼續做足防中暑和防曬措施，定期補充水分並盡量避免劇烈運動。如果出現頭暈、頭痛、噁心、氣促或神志不清等初步中暑症狀，應盡快休息和求助。

本港今日天氣極端酷熱，部分氣象站錄得破紀錄高溫，普遍地區氣溫上升至37度或以上，上水更一度接近40度。
天文台總部今日錄得最高氣溫36.9度，打破1884年有完整氣象觀測以來的最高紀錄。上水最高氣溫為39.8度，是天文台於1980年代開始設置自動氣象站以來的境內新高。
翻查紀錄，除天文台總部外，本港境內今日有另外8個氣象站刷新或追平創站以來最高氣溫紀錄。

本港今日多處錄得破紀錄高溫，但工作暑熱警告只維持在最低級別的黃色警告，引起公眾和媒體關注。
勞工處目前基於暑熱指數發出工作暑熱警告。暑熱指數除了參考氣溫，亦相當著重濕度、空氣流動和太陽熱輻射水平等影響人體散熱和吸熱的因素。
工作暑熱警告自2023年設立以來，從未發出紅色或黑色警告。翻查2014年至今京士柏的暑熱指數紀錄，只有4次達32或以上的紅色警告水平；最高為2019年8月12日的32.4，當日本港最高氣溫為34.0度，但由於是西南氣候風帶來的濕熱，所以暑熱指數較高。
相比之下，本港今日破紀錄高溫，主因是西北風將內陸較熱的空氣帶至沿岸。由於源自內陸的空氣較乾燥，加上今次伴隨一定風力，因此各區暑熱指數不算標青，十個參考站只有濕地公園一度達到紅色警告的標準。
乾燥的破紀錄高溫，伴隨低級別的暑熱警告，是否代表對公眾的風險較低？今日黃色暑熱警告生效期間，一名男子行山不幸中暑身亡。根據衛生署數據，本港過去五年每年有超過200宗因中暑入院的個案，當中死亡個案每年約為2至5宗，影響絕不亞於颱風和暴雨。
暑熱指數的計算，雖然各因素的比重有討論空間，但背後仍有一定科學基礎。至於工作暑熱警告的黃、紅、黑分級，則與近年世界各地提倡的基於影響預警有相似之處。
但制度的最大分別，在於外國由氣象機構基於數據、預報信心等因素作主觀判斷。而本港工作暑熱警告，則由勞工處基於單一數字發出。破紀錄高溫只對應最低級別的暑熱警告，一方面不符合常理和大眾觀感，另一方面亦未必能準確反映相關風險。暑熱警告制度是否存在改善空間，絕對值得有關部門研究。

港初选案11被告获批上诉终审院证明书
香港民主初选案11名被告，获批上诉终审法院证明书。
综合网媒“香港01”、香港《明报》《星岛日报》等报道，47名香港民主派人士因涉嫌组织及参与2020年立法会“35+初选”，被控串谋颠覆国家政权罪。经过漫长诉讼程序，45人被判罪成，在2024年获刑四至10年，另有两人被判无罪。其中12名罪成被告去年7月就定罪和刑期提出上诉，法院在今年2月驳回全部上诉。
当中11人申请向终审法院提出上诉，上诉庭星期一（8月10日）发出证明书，批准吴政亨、郑达鸿、杨雪盈、何启明、黄碧云、何桂蓝、陈志全、邹家成、林卓廷、梁国雄和余慧明向终审法院提出上诉。上次提出上诉的黄子悦这次放弃再上诉。
根据一般上诉程序，若要申请上诉至终审法院，须先向上诉庭申请许可证明书，即使被拒，也可向终审法院申请上诉许可。上述11被告早前也已向终审法院申请上诉许可。

9月研议调整电价 台湾经济部长强调要顾民生稳物价
台湾经济部长龚明鑫受访时称，该部将在9月开会研议调整电价，但强调将坚持“顾民生和稳物价”的立场。
综合台湾中央广播电台和ETtoday新闻云报道，龚明鑫星期一（8月10日）赴立法院经济委员会做专案报告，在会前受访时作出以上表述。
台电近年负担稳定物价任务，吸收国际能源价格涨幅，造成庞大亏损，今年截至上半年亏损达257亿元新台币（10亿新元），累计亏损高达3764亿新台币。近期中东情势反复，国际能源价格不确定性仍高，有报道称，台湾10月电价可能朝冻涨方向研议。
龚明鑫回应时说，电价审议会9月份召开，最后决定还是在审议会。但就经济部立场来说，“照顾民生跟稳定物价是我们一向的政策”。经济部会提供更多证据，适度地表达，让审议会可以了解。
由于今年适逢九合一选举，外界也将这次电价审议与选举联结。龚明鑫强调，审议将“没有选举考量”。

中国法院审理调解2025年霍尔木兹船舶碰撞纠纷
中国媒体报道，广州海事法院成功化解发生在霍尔木兹海峡的一起外轮碰撞纠纷案，这起碰撞事故发生在去年6月，即美伊两国冲突爆发前。
综合新华社和《环球时报》报道，广州海事法院成功审理并调解这起外籍船舶碰撞纠纷案。涉事船舶为安提瓜和巴布达籍“阿达琳”轮和利比里亚籍“前线老鹰”轮。
据报道，两艘船舶2025年6月在霍尔木兹海峡附近海域碰撞后，外籍当事人一致同意适用中国法律，由广州海事法院解决双方实体争议。
法院最终促成双方达成和解协议，化解这起标的额高达1.8亿元（人民币，下同，3413万新元）的外轮碰撞事故责任纠纷。
案件审判长、广州海事法院副院长吴贵宁说，针对双方及分别委托的航海专家对碰撞责任的意见存在较大分歧，案件审理中创新引入海事技术调查官，依托前期封存的核心证据还原碰撞事故经过，清晰界定会遇态势及过错责任，以中立和专业视角最大限度辅助查明案件相关争议事实，为法院公正裁决提供有力支撑。
《环球时报》也报道，围绕碰撞事故引发的损失争议，广州海事法院受理这起船舶碰撞损害责任纠纷本反诉案（同一事故之下双方互相追责、双向索赔，法院将双方诉求合并审理）。
“阿达琳”轮的船东环球航运控股有限公司，向前线老鹰有限公司索赔船舶价值、船期损失等多项损失计1.68亿元，前线老鹰有限公司向环球航运控股有限公司索赔修理费、船期损失等多项损失计1000余万元。
审理过程中，广州海事法院先后召开四次庭前会议，完成举证质证、技术调查筹备等各项前置工作。这起案件今年7月14日公开开庭审理。
据报道，庭审后，广州海事法院推动调解，双方当事人于7月27日达成和解协议。广州海事法院7月31日组织两外轮碰撞事故责任纠纷及所涉租约纠纷案的债权人分配海事赔偿责任限制基金。其中，“阿达琳”轮船方代表专程从境外到广州海事法院递交感谢信并赠送锦旗。
