本港今日多處錄得破紀錄高溫，但工作暑熱警告只維持在最低級別的黃色警告，引起公眾和媒體關注。
勞工處目前基於暑熱指數發出工作暑熱警告。暑熱指數除了參考氣溫，亦相當著重濕度、空氣流動和太陽熱輻射水平等影響人體散熱和吸熱的因素。
工作暑熱警告自2023年設立以來，從未發出紅色或黑色警告。翻查2014年至今京士柏的暑熱指數紀錄，只有4次達32或以上的紅色警告水平；最高為2019年8月12日的32.4，當日本港最高氣溫為34.0度，但由於是西南氣候風帶來的濕熱，所以暑熱指數較高。
相比之下，本港今日破紀錄高溫，主因是西北風將內陸較熱的空氣帶至沿岸。由於源自內陸的空氣較乾燥，加上今次伴隨一定風力，因此各區暑熱指數不算標青，十個參考站只有濕地公園一度達到紅色警告的標準。
乾燥的破紀錄高溫，伴隨低級別的暑熱警告，是否代表對公眾的風險較低？今日黃色暑熱警告生效期間，一名男子行山不幸中暑身亡。根據衛生署數據，本港過去五年每年有超過200宗因中暑入院的個案，當中死亡個案每年約為2至5宗，影響絕不亞於颱風和暴雨。
暑熱指數的計算，雖然各因素的比重有討論空間，但背後仍有一定科學基礎。至於工作暑熱警告的黃、紅、黑分級，則與近年世界各地提倡的基於影響預警有相似之處。
但制度的最大分別，在於外國由氣象機構基於數據、預報信心等因素作主觀判斷。而本港工作暑熱警告，則由勞工處基於單一數字發出。破紀錄高溫只對應最低級別的暑熱警告，一方面不符合常理和大眾觀感，另一方面亦未必能準確反映相關風險。暑熱警告制度是否存在改善空間，絕對值得有關部門研究。

钟睒晱：电商消灭传统中间商主导价格战 吁限制平台权力
中国农夫泉水创始人钟睒晱在一档电视节目时受访时，批评电商消灭传统中间商，主导价格战，呼吁限制平台的权力。
综合观察者网和每日经济新闻报道，钟睒晱上星期六（8月8日）做客中国央视财经《对话》节目，谈到电商平台对社会的影响时说，传统中间商的抽成是公开、恒定的，而平台却可以借助算法对每一笔订单单独调整抽成、干预流量分配。
他认为，平台经济冲击线下零售生态，平台成为无处不在的“中间商”，将城市里的传统经销商都“杀”光。
钟睒晱指出，平台也扼杀了逛街时的即兴感性消费，让人们都将注意力放在手机屏幕上。
与此同时，他也批评平台主导的价格战，对社会生产力造成巨大破坏，“中国现在最需要担心的就是卷价格，不卷质量，不卷高品质，不卷溢价水平”。
钟睒晱以可口可乐和百事可乐的竞争为例说，“他们几乎是商量好的一样对价格敏感，我提价你也提价，从来不往下打价格战。觉得只要低价就能占领市场，实际上是市场经济非常不成熟的表现。”
他相信，平台和价格战压缩了产业链利润，最终受损的是农民、制造商乃至整个实体经济，因此呼吁要限制平台的权力。

上海中心城区暴雨预警升级为橙色
受台风“白海豚”影响，中国上海持续遭遇强降雨，中心城区暴雨预警星期一（8月10日）由黄色升级为橙色，预计未来12小时内，中心城区大部六小时累积降水量将达150毫米以上。持续降雨已导致上海部分道路积水，多条高速公路采取限速措施。
据微信公众号“上海发布”消息，上海市气象台星期一上午10时54分更新中心城区暴雨黄色预警信号为暴雨橙色预警信号，预计未来12小时内，中心城区大部六小时累积降水量将达150毫米以上。
另据澎湃新闻报道，持续大雨也导致上海部分路段积水。同时，为保障通行安全，上海部分高速采取限速措施，当中包括G15沈海高速松江段、G1503绕城高速青浦、松江段等。
白海豚星期天（8月9日）登陆浙江省，中国中央气象台发布最高级别红色预警。这也是继今年7月台风“红霞”后，中央气象台今年第二次发布红色预警。
台风登陆前，各地已展开大规模人员转移。据路透社估计，受影响地区共疏散超过100万人，包括福建省近10万人、浙江台州市约八万人，上海市超过三万人。
