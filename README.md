夏威夷大島週末罕有受颶風侵襲。熱帶氣旋Lala雖然沒有登陸，但其眼壁仍為大島帶來颶風級風力。
大島島上有超過4000米高的冒納凱阿火山，比台灣和呂宋的山脈更高。Lala吹襲期間，山峰甚至一度下雪。
大島地形對熱帶氣旋的影響，亦引起氣象學家關注。結果顯示，今次人工智能路徑預報略勝一籌，解析度更高的颶風模式反而高估了短期路徑波動，錯誤預測Lala登陸大島。
厄爾尼諾期間，中太平洋熱帶氣旋會較活躍。今次夏威夷罕有「打風」，亦是厄爾尼諾正在發展的一大訊號。

受南海低壓系統影響，本港未來一兩日驟雨增多，雨帶掠過期間可能伴隨短暫風力上升。
預料低壓系統未來一兩日會移至海南島以東海域，不排除發展為熱帶氣旋。在中國東南部高壓脊的共同影響下，未來一兩日離岸和高地風勢可能較大，晚間橫瀾島亦一度錄得烈風。
本週後期本港風雨強弱，則視乎低壓系統後續動向及發展。從集成電腦預報可見，低壓系統抵達海南島以東海域後，實際路徑仍有較大變數，須視乎其中心整合位置，以及與台灣以東海域另一低壓系統的互動。
MET WARN 會繼續關注此低壓系統的發展。週末計劃進行戶外活動的讀者，應留意天氣變化可能帶來的影響。

天文台指，該低壓區可能在接近週末以偏北方向靠近北部灣至雷州半島一帶，亦有可能轉向偏東方向靠近廣東沿岸。

海南島附近的熱帶低氣壓預料未來數日在北部灣一帶徘徊。雖然本週內對本港天氣直接影響不大，但風暴迷路對其後續發展有何影響？
風暴成為迷途羔羊的主因，是台灣以東的低渦阻擋副熱帶高壓脊向西伸展。副高山高皇帝遠時，引導氣流會較微弱，風暴只能緩慢移動，移動方向亦較不明確。
預料風暴滯留北部灣時會逐漸增強。值得留意的是，北部灣的狹窄海灣地形有利低空輻合，促使風暴建立較緊密的核心環流。另外，北部灣海溫亦較高，因此風暴增強幅度會否大於預期有待觀察。
由於風暴本週內會與本港保持相當距離，因此短期內直接影響不大。至於風暴後期的移動路徑，須視乎台灣以東低渦的發展和動向，以及熱帶氣旋沙德爾的移動路徑。
按照現時預測，位於北部灣的風暴有可能在下週初轉向偏東方向移動，但仍有不少變數，暫時未能判斷風暴下週對本港的影響。

位於北部灣的熱帶氣旋已獲日本氣象廳命名為紫檀。紫檀是首次使用的名字，取代六年前吹襲菲律賓而除名的莫拉菲。
紫檀過去一日對流繼續發展，但最新微波掃描顯示風暴仍呈切離型態。紫檀增強幅度和速度須視乎垂直風切變的變化。
紫檀未來兩三日會在北部灣徘徊，隨後會否靠近本港仍有變數。天文台先前表示，會密切監察其動向及本地風力變化，評估需否在下週初發出熱帶氣旋警告。

巴拿马干旱限制运河通行，对美国经济的冲击或甚于霍尔木兹
受创纪录强度的厄尔尼诺影响，巴拿马运河正遭遇严重干旱，水位持续走低。8月初，数十艘船只在运河两端排队等待通行，部分已滞留超一周——一艘集装箱船甚至支付了创纪录的400万美元以插队通过。自5月以来，巴拿马城降雨量仅为常年同期的75%，西部城市戴维过去90天更只有60%。巴拿马运河管理局表示，整个运河流域累计降雨量较历史均值低34%，迫使运河调整运营以应对水位下降。自9月起，运河将把船舶最大吃水深度从通常的50英尺降至48英尺，并预计进一步下调，同时每日通行量也将逐步缩减至32艘。地中海航运等公司已宣布上调运河附加费，涨幅将于9月12日生效。这场危机正通过供应链迅速传导——不仅药品、电子产品等经运河运输的商品面临涨价压力，还会对陆路运输产生连锁反应。若运河持续延误，船只将改道美国西海岸港口，货物再经铁路或卡车转运至全美。这将挤占陆路运力、推高运费，进而拉升从未经运河运输的各类商品价格。伊朗对霍尔木兹海峡的强硬立场已推高油价。美国能源出口若经运河受阻，试图以美国原油替代中东供应的亚洲国家将面临能源成本双向上涨。史汀生中心高级研究员格丹警告，运河危机正与霍尔木兹海峡冲击叠加，“运输成本不仅传导至消费价格，更因能源获取成本上升而推高一切物价”。国际战略研究中心（CSIS）专家齐默尔指出，霍尔木兹海峡对美国直接影响有限，但约40%的美国集装箱运输依赖巴拿马运河。8月10日特朗普已延长豁免期，允许外籍船只在美国港口间运输能源商品，以缓解伊朗战争引发的油价压力。卡托研究所数据显示，截至8月11日，豁免期已有至少49艘外籍船只经巴拿马运河通行，目前215艘船只通过该运河完成航程。若运河通行量降至2023-2024年干旱水平，美国经济将面临更大冲击——不过影响更多体现在手机、电脑、农产品等消费品价格上，而非能源价格。

达利欧警告美国债务危机风险，建议增加黄金配置
格隆汇8月22日｜亿万富翁瑞·达利欧表示，投资者应该降低债券仓位并将不超过15%的资金投入黄金，以此对冲他认为三年左右会爆发的美国债务危机风险。达利欧发帖说，应分散投资于各类资产和财政状况强劲的国家。达利欧建议，低配债券并将投资组合的约10%至15%配置黄金以及“少量”比特币。他说这样做既能降低风险又能提高收益。达利欧长期以来一直就政府债务不断攀升的危险大声疾呼。美国长期国债收益率已升至多年来的最高位，而其最大债权国日本为捍卫本币而抛售美债。财政部长斯科特·贝森特为遏制债券暴跌本周宣布了扩大长债回购的计划，然而这一出人意料的举措迄今为止除了短暂托底外收效甚微。达利欧估计，今年美国政府财政收入约为5.5万亿美元，而支出高达7.5万亿美元，留下了2万亿美元的缺口。仅利息支出就将达到约1万亿美元，此外还有约10万亿美元的债务需要再融资。他预计，若不改弦易辙美国可能在“三年内、上下浮动两年”爆发债务危机。
